# MVP Roadmap

## Phase 1: Foundation

- Repository structure.
- CI tests.
- API health endpoint.
- Store creation API.
- Store slug validation.
- Environment example.
- Frontend shell for owner and customer flows.
- Payment placeholder endpoint without real provider integration.

## Phase 2: Owner Basics

- Owner registration.
- Owner login.
- Create store profile.
- Update store profile.
- Add product.
- List products.
- Add service.
- List services.

## Phase 3: Customer Storefront

- Public store homepage.
- Product listing.
- Product detail page.
- Service listing.
- Cart foundation.
- Checkout placeholder.
- Booking placeholder.

## Phase 4: Orders and Bookings

- Create order.
- View owner order list.
- Update order status.
- Create booking.
- View owner booking list.

## Phase 5: Production Readiness

- PostgreSQL persistence.
- Authentication hardening.
- File uploads.
- Payment integration.
- Arabic/English localization.
- Deployment pipeline.

## One-Month Delivery Plan

### Week 1: Foundation and Owner Flow

- Stabilize repository structure.
- Build owner auth model.
- Build store profile management.
- Build product and service CRUD.
- Keep tests passing in CI.

### Week 2: Customer Storefront

- Build public storefront pages.
- Build product and service browsing.
- Build cart and booking forms.
- Add Arabic/English layout foundation.

### Week 3: Orders, Bookings, and Admin Polish

- Create product orders.
- Create service bookings.
- Add owner order and booking views.
- Add status updates.
- Add basic dashboard metrics.

### Week 4: Hardening and Demo Release

- Add PostgreSQL persistence.
- Add file upload foundation.
- Improve validation and error states.
- Prepare demo data.
- Deploy staging version.
- Record test results and handoff notes.
